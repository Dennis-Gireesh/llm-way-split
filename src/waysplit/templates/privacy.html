Local policy · read before connecting a destination

Privacy boundary

WaySplit is self-hosted software. The maintainers do not receive your statements merely because you install it. Your chosen host, model endpoint, destination, backups, and logs determine the real boundary.

What stays local by default

Statement parsing, OCR, normalized bill data, deterministic allocation, reconciliation, duplicate detection, previews, and the tamper-evident audit ledger run on the operator-controlled host. Source uploads are removed after extraction by default. Normalized bills, evidence excerpts, household rules, fingerprints, remote IDs, and audit events remain in SQLite until the operator removes the data directory.

Local model disclosure

The selected Ollama or OpenAI-compatible endpoint receives the text or page images needed for extraction. Version 0.1 rejects remote-model mode; “OpenAI-compatible” describes the API shape of a local endpoint, not a cloud fallback.

Splitwise disclosure and consent

Only after explicit confirmation, WaySplit sends the displayed group ID, date, currency, description, notes, total, payer/member IDs, paid shares, and owed shares. It does not attach the original statement, full OCR text, raw model response, credentials, or local audit history.

Splitwise then controls the remote expense under its own privacy practices. Splitwise may collect information about this integration’s API use (“API Usage Data”) and, under its published API terms, may use that information for any business purpose.

The operator must show this disclosure to every affected Splitwise end user and obtain their explicit consent before processing their Splitwise materials. One operator cannot consent for another participant. Account consent is separate from confirming each expense.

This alpha is scoped to personal, noncommercial self-hosting. Operators must review the current Splitwise API terms and Splitwise privacy policy; the project does not claim that commercial or fee-based use is permitted.

Credentials and telemetry

A Splitwise token pasted into the browser is kept only in that tab’s memory and sent to the local service for the requested connection, post, or rollback. It is not written to browser storage, SQLite, or the audit ledger; server-side destination credentials are unsupported. There is no browser password or unlock token in this release: keep the loopback service private because anyone who can reach it can use it. WaySplit {{ version }} sends no maintainer analytics or crash reports.

Operator responsibilities

Tell household members what is processed, obtain required consent, restrict host and network access, use disk encryption, protect backups, review every preview, and remove destination data through the provider when needed. Do not upload real statements to GitHub issues, pull requests, CI, or maintainers.
